# Automatic Fantasy Island Generator for QGIS

Automatically generates rich fantasy islands with features including:
* Terrain
* Cities and Villages
* Shops
* Farms
* Rivers
* Monuments
* Forests
* Lakes
* Swamps
* Mountains
* Quarries
* Deserts
* Seas
* Seafarers

It will automatically generate fantasy-style names for each feature.

# How to Use
1. Download the repo
2. Open the .QGZ file in QGIS, and run the Fantasy Map Model from the toolbox to generate an island
3. Run Terrain.py on the output layer via the QGIS Python console and it will automatically populate the island
